◆ wakePinReleased()

static bool wakePinReleased ( gpio_num_t  pin)
static

Check that an active-low wake input is idle (high) before sleeping.

EXT1 in ANY_LOW mode is level-triggered: a pin still low when the chip goes to sleep wakes it again immediately. That happens for real in two ways: the rain gauge reed still closed at the end of a quick-path wake (the same tip would be counted twice), and an input stuck low for good (bucket resting on the reed, water in an outdoor connector, button jammed) — which would turn deep sleep into a wake loop draining the battery in hours.

Returns immediately when the pin is already high (the normal case, no cost); otherwise waits for a stable release up to a timeout.

Parameters
pinActive-low wake input.
Returns
true if the pin is idle and can be armed as a wake source.
